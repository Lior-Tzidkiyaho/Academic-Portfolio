## 1. AI Interview Preparation Agent
**Focus: AI, Product, Prompt Engineering**

A conversational AI agent that simulates a real job interview — it asks role-specific
questions, lets the user answer, then gives a model answer with feedback for improvement.

* **Architecture:** a three-agent LangChain pipeline
  1. **Analysis Agent** — extracts key themes from the CV and job description
  2. **Generation Agent** — writes a focused, professional interview question
  3. **Quality-Control Agent** — validates the question and prevents hallucinations
* **Two implementations:**
  * [`interview_agent_langchain.py`](interview_agent_langchain.py) — full LangChain SequentialChain version
  * [`interview_agent_api.py`](interview_agent_api.py) — direct OpenAI GPT-4o API version
* **Tech:** Python | LangChain | OpenAI GPT-4o API | Prompt Engineering
